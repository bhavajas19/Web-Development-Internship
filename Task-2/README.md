# Task 2 - To-Do List Web App

## Web Development Internship - Elevate Labs

As part of my Web Development Internship at **Elevate Labs**, I completed **Task 2** by building a dynamic To-Do List Web Application using HTML, CSS, and Vanilla JavaScript.

## About the Project

For this task, I developed a simple and responsive To-Do List application that allows users to manage their daily tasks directly through the browser.

The application allows users to add new tasks, mark tasks as completed, delete tasks, and clear completed tasks without requiring a page refresh.

## Features

- Add new tasks
- Mark tasks as completed
- Remove tasks
- Clear completed tasks
- Task counter
- Add tasks using the Enter key
- Responsive user interface
- Instant UI updates without page reload

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- Event Listeners
- CSS Flexbox
- Media Queries
