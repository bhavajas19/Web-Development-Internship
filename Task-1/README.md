# Web Development Internship

## Day 01 - Responsive YouTube-Style Landing Page

This project was created as part of my Web Development Internship.

The task was to build a responsive web page using HTML and CSS, focusing on layout, Flexbox/Grid, responsive design, and media queries.

## Project Overview

For this task, I created a YouTube-inspired homepage with:

- Header and navigation
- YouTube-style logo
- Search bar
- Sidebar navigation
- Category buttons
- Video cards
- Video thumbnails
- Channel information
- Responsive layout
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features

### Header
- Menu button
- YouTube-style logo
- Search bar
- Notification and profile icons

### Sidebar
- Home
- Shorts
- Subscriptions
- History
- Playlists
- Your Videos
- Watch Later
- Liked Videos
- Explore categories

### Video Section
- Responsive video grid
- Video thumbnails
- Video duration
- Channel information
- Views and upload time
- Hover effects

### Responsive Design

The website is responsive for:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout according to screen size.
